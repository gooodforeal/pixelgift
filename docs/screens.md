# Экраны приложения

Демонстрация основных экранов веб-клиента Pixelgift. Скриншоты сняты с локального стенда (`docker compose`, viewport 1440×900).

## Публичные

### Лендинг

Маршрут: `/`

![Лендинг](images/screens/landing.png)

Публичная витрина продукта: ценность сервиса и вход в приложение.

### Вход через Telegram

Маршрут: `/login`

![Вход](images/screens/login.png)

Беспарольный логин: QR / deep-link в Telegram-бот, ожидание подтверждения.

### Каталог товаров

Маршрут: `/products`

![Каталог](images/screens/products.png)

Список пакетов кредитов и товаров для пополнения баланса.

### Карточка товара

Маршрут: `/products/:productId`

![Товар](images/screens/product.png)

Детали SKU, цена и покупка.

### Поддержка

Маршрут: `/support`

![Поддержка](images/screens/support.png)

Создание тикета поддержки (вложения, описание проблемы).

### Публичный бокс получателя

Маршрут: `/b/:slug`

![Публичный бокс](images/screens/public-box.png)

Страница получателя: открытие подарка, пароль/отложенная активация, контент бокса.

## Авторизованные

### Дашборд — мои боксы

Маршрут: `/app`

![Дашборд](images/screens/dashboard.png)

Коллекция боксов пользователя: статусы, ссылки, создание нового бокса.

### Профиль

Маршрут: `/app/profile`

![Профиль](images/screens/profile.png)

Профиль, баланс, история операций и настройки уведомлений.

### Редактор бокса

Маршрут: `/app/boxes/new`, `/app/boxes/:boxId`

![Редактор бокса](images/screens/box-editor.png)

Пошаговый wizard: оформление → детали → содержимое → публикация → сертификат. Ассистент «Гифти» в углу.

## Админка

Доступна пользователям с `is_admin`.

### Панель

Маршрут: `/app/panel`

![Админ-панель](images/screens/admin-panel.png)

Точка входа в административные разделы.

### Товары

Маршрут: `/app/panel/products`

![Админ: товары](images/screens/admin-products.png)

CRUD каталога товаров и скидок.

### Промокоды

Маршрут: `/app/panel/promo-codes`

![Админ: промокоды](images/screens/admin-promo-codes.png)

Управление промокодами и лимитами использований.

### Тикеты поддержки

Маршрут: `/app/panel/support`

![Админ: поддержка](images/screens/admin-support.png)

Очередь обращений пользователей.

### Дизайны боксов

Маршрут: `/app/panel/designs`

![Админ: дизайны](images/screens/admin-designs.png)

Каталог тем оформления боксов (превью, рейтинг, активность).
